# Tahfidz Tracker

Buat aplikasi web siap pakai Pencatatan Tahfidz Santri Pesantren Darul Ilmi dalam bahasa Indonesia. Implementasikan backend Lovable Cloud terlebih dahulu agar semua data tersimpan dan saling terhubung, lalu bangun aplikasi modern, responsif, berwarna, dan mudah digunakan dengan sidebar tepat 6 menu utama: Dashboard, Data Santri, Data Ustadz Pengampu, Input Setoran Tahfidz, Laporan Bulanan Santri, Pengaturan. Penuhi seluruh spesifikasi pengguna: CRUD, pencarian/filter, 50 data dummy santri kelas 7–12, 5 ustadz dummy, setoran Sabaq/Sabqi/Manzil lengkap dengan seluruh aturan dan data harian satu semester, dashboard dengan statistik/grafik/ranking aktual, laporan bulanan dan unduh PDF, serta pengaturan nama/logo/theme dengan 6 template. Pastikan dashboard, grafik, ranking, progress, laporan, dan perubahan data benar-benar memakai database/data setoran aktual; semua menu berfungsi dan terhubung. Uji dan perbaiki error sampai checklist terpenuhi.
